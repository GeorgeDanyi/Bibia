# PhysioCare Landing Page

A modern, responsive landing page for a physiotherapy practice built with Next.js 14, TypeScript, and TailwindCSS.

## Features

- **Modern Design**: Clean, professional design with mobile-first responsive layout
- **Next.js 14**: Built with the latest App Router for optimal performance
- **TypeScript**: Fully typed for better development experience
- **TailwindCSS**: Utility-first CSS framework for rapid styling
- **shadcn/ui**: Beautiful, accessible UI components
- **Responsive**: Optimized for mobile, tablet, and desktop devices

## Sections

1. **Hero Section**: Eye-catching headline with CTA button
2. **3 Steps**: Clear process explanation with action buttons
3. **Therapy Benefits**: 4 benefit cards with icons and descriptions
4. **Insurance**: Insurance provider logos and contribution information
5. **Newsletter**: Email subscription form
6. **Call to Action**: Final conversion section with 3 key benefits
7. **Footer**: Complete footer with contact info, links, and social icons

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is ready for deployment on Vercel:

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy with zero configuration

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: TailwindCSS
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **Deployment**: Vercel-ready
